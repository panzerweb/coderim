# Add Two Numbers

A tiny problem for testing the submission flow. Read two integers and print their sum.

## Input specification

Two whitespace-separated integers A and B, each from -1,000,000,000 to 1,000,000,000.

## Output specification

Print A + B as one integer. Do not print prompts or labels.

## Practice information

Suggested duration: 5 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
