# Longest Unique Segment

Find the length of the longest consecutive segment containing no repeated values. The segment must be contiguous in the original list.

## Input specification

Read N (1 <= N <= 100,000), followed by N integers from -1,000,000 to 1,000,000. Integers may be separated by any whitespace.

## Output specification

Print the maximum segment length as one integer.

## Practice information

Suggested duration: 40 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
