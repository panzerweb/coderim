# G-Tree Node Ancestor Query

A tree has nodes numbered 1 through N and is rooted at node 1. For each pair U V, determine whether U is an ancestor of V. Every node is an ancestor of itself. The root never changes.

## Input specification

Read N (1 <= N <= 100,000), followed by exactly N-1 parent-child pairs P C describing a valid connected tree rooted at 1. Edges may appear in any order. Read Q (1 <= Q <= 100,000), followed by Q pairs U V. All labels are between 1 and N.

## Output specification

Print YES or NO for every query, in input order.

## Practice information

Suggested duration: 40 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
