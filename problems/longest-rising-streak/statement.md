# Longest Rising Streak

A weather station records daily temperatures. Find the longest consecutive streak where every day's temperature is strictly higher than the previous day's. Days must be adjacent in the original list; equal temperatures break a streak.

## Input specification

The first integer is T (1 <= T <= 10). For each test case, read N (1 <= N <= 100,000), then N temperatures from -1,000,000 to 1,000,000. The sum of N across test cases is at most 100,000. Whitespace may separate the integers across lines.

## Output specification

Print one streak length per test case, in input order. A singleton streak has length 1.

## Practice information

Suggested duration: 20 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
