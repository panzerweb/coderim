# Palindrome Check

Determine whether a line reads the same forward and backward when comparing only ASCII letters and digits. Ignore letter case, punctuation, and spaces. A line containing no letters or digits is a palindrome.

## Input specification

Read one line containing 1 to 100,000 printable ASCII characters (codes 32 through 126). The line ending is not part of the text. Leading and trailing spaces may occur.

## Output specification

Print YES if the normalized text is a palindrome; otherwise print NO.

## Practice information

Suggested duration: 20 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
