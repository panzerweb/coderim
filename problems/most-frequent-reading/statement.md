# Most Frequent Reading

Find the most frequent reading. If several values have the same highest frequency, choose the smallest numeric value.

## Input specification

Read N (1 <= N <= 100,000), then N integers from -1,000,000 to 1,000,000. Integers may be separated by any whitespace.

## Output specification

Print the selected value and its frequency, separated by a space.

## Practice information

Suggested duration: 20 minutes (informational). Execution target: 2 seconds per case. Memory target: 256 MB, unenforced by the local executor.
